# Retained Quaternius character sources

These are the creator's free **Standard** downloads obtained through the public
“No thanks, just take me to the downloads” workflow on 13 October 2026. No Pro or
paid Source file was requested. Originals are retained unchanged locally; ZIPs,
extracted binary sources and Blender masters are excluded from Git. Licenses,
provenance and selected smaller native imports remain committed. See
[local asset storage](../../../../tools/native-assets/README.md) for hash-verified
large-texture restoration and the separate private publication prerequisites.

Each archive contains an explicit CC0 public-domain dedication. Its original
license text is also copied here. `provenance.json` records the exact upload IDs,
dates, archive sizes, archive hashes and license hashes. The CC0 legal code is
retained as `CC0-1.0.txt`. Credit to Quaternius is preserved voluntarily.

The creator's general [license page](https://quaternius.com/license.html) now
shows QAL v1.0, dated 28 August 2026, with a restriction on standalone asset
redistribution. That general statement differs from these older archives and
their pack pages, which explicitly label these Standard releases CC0. PU Town
uses these exact retained CC0 releases; it does not assume every current or
future Quaternius asset has the same source-redistribution permission.

- [Modular Character Outfits — Fantasy](https://quaternius.com/packs/modularcharacteroutfitsfantasy.html), [Standard download](https://quaternius.itch.io/modular-character-outfits-fantasy)
- [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html), [Standard download](https://quaternius.itch.io/universal-animation-library)

The Standard character archive actually includes Superhero male/female full
bodies, eight hair/eyebrow/beard options and textured exports. The outfit archive
includes four Peasant/Ranger outfits, matching modular parts and alternate
textures. The animation archive includes 43 actions in both in-place and root
motion files. Paid-only models, editor projects, custom shaders and original
`.blend` files are not included.

Private extracted imports live in `campus/assets/avatars/sources/quaternius/`.
The project-created editable `.blend` derivatives are separate from the
creator's unchanged exports. They retain imported topology, UVs, textures,
skinning and rig conventions, and combine chosen clothing/head/hair components.
The active Ash/Lea v2 derivatives underwent actual Unity pose/material review
before atomic publication through the private workshop. Source archives and
immutable v1/v2 Blender masters are retained separately; future changes require
a new registered revision and review. Platform compilation and model-pose
inspection do not establish packaged gameplay or Windows runtime acceptance.
