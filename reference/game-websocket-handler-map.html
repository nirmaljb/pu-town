GameWebSocketHandler architecture map

Spring calls the lifecycle hooks. The handler turns those callbacks into serialized Room transitions and queued protocol events.

Spring owns

Transport lifecycle

Upgrade HTTP at /ws/game, create a WebSocketSession, deliver text frames, and report closure.

PU Town owns

Game semantics

Issue Player IDs, decode protocol v1, manage Room membership, validate movement, order events, and protect slow connections.

Callback → responsibility

afterConnectionEstablished

Create a PlayerState; index it by session and Player ID; create its outbox. Connection is not Join.

handleTextMessage

Find the Player, serialize that Player's callbacks, decode strict JSON, then route Join, Leave, or Move.

afterConnectionClosed

Remove registries and outbox; if the Player still belongs to a Room, end membership as disconnected.

@PreDestroy

Stop the executor that drains outbound queues when Spring destroys the application component.

The four concurrency boundaries

1 · Registries
ConcurrentHashMap makes shared lookup and update safe.
2 · One Player
synchronized (player) orders inbound handling against close cleanup.
3 · One Room
RoomManager.serialized orders membership, state changes, and event creation.
4 · One connection
ConnectionOutbox serializes socket writes, bounds backlog, and coalesces movement.

Message outcomes

Join

Others receive player_joined; the joining Player receives one complete room_snapshot.

Accepted move

State becomes authoritative; everyone in the Room—including the sender—receives player_moved.

Leave

Others receive reason left; the leaving Player receives room_left. Closing later does not duplicate departure.

Disconnect

Remaining Players receive player_left with reason disconnected; no acknowledgement goes to the closed connection.

One-sentence architecture: A singleton Spring text handler translates connection callbacks and strict JSON commands into authoritative, per-Room serialized transitions, then publishes ordered messages through a bounded asynchronous outbox per connection.
