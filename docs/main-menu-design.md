# Main menu visual design

Confirmed on 7 September 2026. This is a visual update to the existing joining interface.

The direction is a friendly Earth-based town at dusk, expressed through midnight blue (#19233d), slate (#303e5b), muted border blue (#70809a), cream (#fff0c9), and amber (#efbd72). A large retro title sits above a compact framed form. The background uses a faint grid and ambient lighting rather than a depicted town. Form text remains in the system sans-serif font; the title uses a bold monospace face with a stepped shadow.

The menu preserves Display Name, Create Room, Room Code, and Join Room, plus existing validation, remembered names, keyboard navigation, loading states, and errors. It adapts to narrow screens and respects reduced-motion preferences.

This pass includes no sprites, illustrated scenery, Avatar selection, playable preview, gameplay restyling, or proximity voice/video functionality. Gameplay may receive the visual treatment separately. No domain terms or architectural decisions change.
