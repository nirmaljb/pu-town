# Day voice (#48)

Each living Day speaker publishes in an isolated media room. The backend issues
hidden receive-only listening grants only for accepted same-area positions within
five tiles. Independent grants prevent hearing through another listener. Gain is
one within two tiles and fades to zero at five; changes arrive through the strict
`voice_peers` contract. ADR 0018 records the additional connection cost.

The controlled-clock WebSocket test verifies private peer lists, independent
third-Player hearing, gain changes, building-boundary exclusion and irrevocable
movement/phase retirement.
Backend full suite: 110 tests passed. Frontend full suite: 88 tests passed;
typecheck and build passed, including strict peer decoding and frame application.

`tools/voice/verify_day.py` passed against the current backend and pinned LiveKit
1.13.7 using four Game connections and real native WebRTC clients: nonzero nearby
PCM, hidden listeners, independent third-Player hearing, rejection of a modified
client’s foreign-track subscription while authorized audio continued, full gain
within two tiles, actual media disconnection after movement, and stale-token 403.
The native SDK emitted deallocation assertions during interpreter shutdown after
the successful checks; the script exited zero. This is native media evidence.

The user explicitly waived further browser automation. Browser UI and hardware
microphone acceptance, ten-Player media capacity, and human balance playtests
remain unverified; native checks do not establish these outcomes.

Native gain assertions check the server’s gain values; browser attenuation was
not measured. Standards review found no documented breach and one optional
authorization-parameter grouping suggestion. The Spec review’s missing building
voice assertion was added and passed in the full backend suite.
