# PU Town interface artwork

`timber.svg` and `paper.svg` are original, code-authored pixel-grid frames for PU Town. Their palette follows the existing town artwork. CSS uses nine-slicing to preserve corners while panels resize. No third-party UI pack is redistributed.

`silkscreen.ttf` is Silkscreen Regular by The Silkscreen Project Authors, downloaded from https://github.com/google/fonts/tree/main/ofl/silkscreen. Its SIL Open Font License is included as `silkscreen-OFL.txt`. Titles use this local font; longer text uses system fonts for readability. No runtime font service is required.
